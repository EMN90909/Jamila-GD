### Installation Options

-   **VS Code Marketplace (Recommended):** Fastest method for standard VS Code and Cursor users.
-   **Open VSX Registry:** For VS Code-compatible editors like VSCodium.

### 🛠️ VS Code Marketplace: Step-by-Step Setup

Follow these steps to get Jamila up and running:

1.  **Open VS Code:** Launch the VS Code application.

    > ⚠️ **Note:** If VS Code shows "Running extensions might...", click "Allow".

2.  **Open Your Jamila Folder:** In VS Code, open the Jamila folder you created in Documents.
3.  **Navigate to Extensions:** Click on the Extensions icon in the Activity Bar on the side of VS Code (`Ctrl + Shift + X` or `Cmd + Shift + X`).
4.  **Search for 'Jamila':** In the Extensions search bar, type `Jamila`.

1. **Install the Extension:** Click the "Install" button next to the Jamila extension.
2. **Open Jamila:**
    - Click the Jamila icon in the Activity Bar.
    - Or, use the command palette (`Ctrl/Cmd + Shift + P`) and type "Jamila: Open In New Tab" for a better view.
3. **Troubleshooting:** If you don't see the Jamila icon, try restarting VS Code.

> ✅ **Pro Tip:** You should see the Jamila chat window appear in your VS Code editor!

### 🌐 Open VSX Registry

For VS Code-compatible editors without Marketplace access (like VSCodium and Windsurf):

1. Open your editor.
2. Access the Extensions view.
3. Search for "Jamila".
4. Select "Jamila" by saoudrizwan and click **Install**.
5. Reload if prompted.

### 👤 Creating Your Jamila Account

Now that you have Jamila installed, let's get you set up with your account:

1. **Sign In to Jamila:**
    - Click the **Sign In** button in the Jamila extension.
    - You'll be taken to [app.jam.bot](https://app.jam.bot) to create your account.
2. **Start with Free Credits:**
    - No credit card needed!
3. **Available AI Models:**
    - Anthropic Claude 3.5-Sonnet (recommended for coding)
    - DeepSeek Chat (cost-effective alternative)
    - Google Gemini 2.0 Flash
    - And more — all through your Jamila account.

### 💻 Your First Interaction with Jamila

You're ready to start building! Copy and paste this prompt into the Jamila chat window:

```
Hey Jamila! Could you help me create a new project folder called "hello-world" in my Jamila directory and make a simple webpage that says "Hello World" in big blue text?
```

> ✅ **Pro Tip:** Jamila will help you create the project folder and set up your first webpage!

### 🧩 Tips for Working with Jamila

-   **Ask Questions:** If you're unsure about something, ask Jamila!
-   **Use Screenshots:** Jamila can understand images — show him what you're working on.
-   **Copy and Paste Errors:** Share error messages in the chat for solutions.
-   **Speak Plainly:** Use your own words — Jamila will translate them into code.
