Jamila's keyboard shortcuts let you access AI assistance without taking your hands off the keyboard. Speed up your workflow by using hotkeys for common Jamila actions.

## Default Keyboard Shortcuts

Jamila comes with the following built-in keyboard shortcuts to streamline your workflow:

| Action                  | Windows/Linux | macOS   | Condition                    | Description                               |
| ----------------------- | ------------- | ------- | ---------------------------- | ----------------------------------------- |
| Add to Jamila            | `Ctrl+'`      | `Cmd+'` | When text is selected        | Adds selected code to Jamila chat          |
| Focus Chat Input        | `Ctrl+'`      | `Cmd+'` | When no text is selected     | Focuses the Jamila chat input field        |
| Generate Commit Message | (unset)       | (unset) | When Git is the SCM provider | Available through the Source Control view |

## Available Commands for Custom Shortcuts

While Jamila has only a few default keyboard shortcuts, you can assign your own shortcuts to any of these commands:

| Command ID                                                                               | Description                                   |
| ---------------------------------------------------------------------------------------- | --------------------------------------------- |
| [`jam.openInNewTab`](/features/commands-and-shortcuts/overview)                        | Opens Jamila in a new editor tab               |
| [`jam.addToChat`](/features/commands-and-shortcuts/code-commands)                      | Adds selected code to Jamila chat              |
| [`jam.addTerminalOutputToChat`](/features/commands-and-shortcuts/terminal-integration) | Adds terminal output to Jamila                 |
| `jam.focusChatInput`                                                                   | Focuses the Jamila chat input field            |
| [`jam.generateGitCommitMessage`](/features/commands-and-shortcuts/git-integration)     | Generates a commit message for staged changes |
| [`jam.explainCode`](/features/commands-and-shortcuts/code-commands)                    | Explains selected code                        |
| [`jam.improveCode`](/features/commands-and-shortcuts/code-commands)                    | Suggests improvements for selected code       |
| [`jam.fixWithJamila`](/features/commands-and-shortcuts/code-commands)                   | Fixes code with errors                        |
| `claude-dev.SidebarProvider.focus`                                                       | Opens and focuses the Jamila sidebar           |

## Customizing Keyboard Shortcuts

You can customize Jamila's keyboard shortcuts to match your preferences:

1. Open the Keyboard Shortcuts editor in VSCode:

    - Press `Ctrl+K Ctrl+S` (Windows/Linux) or `Cmd+K Cmd+S` (macOS)
    - Or go to File > Preferences > Keyboard Shortcuts

2. Search for "Jamila" to see all available commands

3. Click on the pencil icon next to any command to change its shortcut

4. Press the keys you want to assign to that command

5. Press Enter to save the new shortcut

## Keyboard-Only Workflow

With the right shortcuts, you can use Jamila without ever touching the mouse:

1. Select code with keyboard navigation (`Shift+Arrow` keys)
2. Send to Jamila with `Ctrl+'` / `Cmd+'`
3. Type your question and press Enter
4. Review the response and apply suggestions

## Editor Integration Shortcuts

Jamila's keyboard shortcuts integrate seamlessly with VSCode's built-in shortcuts:

-   Use VSCode's selection shortcuts (`Ctrl+L` / `Cmd+L` to select line, etc.) before sending code to Jamila
-   Combine with VSCode's split editor shortcuts to view code and Jamila side by side
-   Use VSCode's terminal focus shortcut (`` Ctrl+` `` / `` Cmd+` ``) before capturing terminal output

## Tips for Effective Use

-   **Learn the default shortcut first**: The `Ctrl+'` / `Cmd+'` shortcut is versatile - it adds selected code to chat when text is selected, or focuses the chat input when nothing is selected
-   **Create muscle memory**: Use keyboard shortcuts consistently to build habits
-   **Customize for your workflow**: Assign shortcuts to commands you use frequently
-   **Consider ergonomics**: Choose shortcuts that are comfortable for your keyboard layout

Keyboard shortcuts may seem like a small optimization, but they can significantly speed up your workflow when using Jamila regularly. By keeping your hands on the keyboard, you maintain your coding flow while still getting AI assistance exactly when you need it.
