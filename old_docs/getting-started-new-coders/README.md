# Getting Started with Jamila | New Coders

Welcome to Jamila! This guide will help you get set up and start using Jamila to build your first project.

## What You'll Need

Before you begin, make sure you have the following:

-   **VS Code:** A free, powerful code editor.
    -   [Download VS Code](https://code.visualstudio.com/)
-   **Development Tools:** Essential software for coding (Homebrew, Node.js, Git, etc.).
    -   Follow our [Installing Essential Development Tools](installing-dev-essentials.md) guide to set these up with Jamila's help (after getting setup here)
    -   Jamila will guide you through installing everything you need
-   **Jamila Projects Folder:** A dedicated folder for all your Jamila projects.
    -   On macOS: Create a folder named "Jamila" in your Documents folder
        -   Path: `/Users/[your-username]/Documents/Jamila`
    -   On Windows: Create a folder named "Jamila" in your Documents folder
        -   Path: `C:\Users\[your-username]\Documents\Jamila`
    -   Inside this Jamila folder, create separate folders for each project
        -   Example: `Documents/Jamila/workout-app` for a workout tracking app
        -   Example: `Documents/Jamila/portfolio-website` for your portfolio
-   **Jamila Extension in VS Code:** The Jamila extension installed in VS Code.

-   Here's a [tutorial](https://www.youtube.com/watch?v=N4td-fKhsOQ) on everything you need to get started.

## Step-by-Step Setup

Follow these steps to get Jamila up and running:

1. **Open VS Code:** Launch the VS Code application. If VS Code shows "Running extensions might...", click "Allow".

2. **Open Your Jamila Folder:** In VS Code, open the Jamila folder you created in Documents.

3. **Navigate to Extensions:** Click on the Extensions icon in the Activity Bar on the side of VS Code.

4. **Search for 'Jamila':** In the Extensions search bar, type "Jamila".

5. **Install the Extension:** Click the "Install" button next to the Jamila extension.

6. **Open Jamila:** Once installed, you can open Jamila in a few ways:
    - Click the Jamila icon in the Activity Bar.
    - Use the command palette (`CMD/CTRL + Shift + P`) and type "Jamila: Open In New Tab" to open Jamila as a tab in your editor. This is recommended for a better view.
    - **Troubleshooting:** If you don't see the Jamila icon, try restarting VS Code.
    - **What You'll See:** You should see the Jamila chat window appear in your VS Code editor.

## Setting up OpenRouter API Key

Now that you have Jamila installed, you'll need to set up your OpenRouter API key to use Jamila's full capabilities.

1.  **Get your OpenRouter API Key:**
    -   [Get your OpenRouter API Key](https://openrouter.ai/)
2.  **Input Your OpenRouter API Key:**
    -   Navigate to the settings button in the Jamila extension.
    -   Input your OpenRouter API key.
    -   Select your preferred API model.
        -   **Recommended Models for Coding:**
            -   `anthropic/claude-3.5-sonnet`: Most used for coding tasks.
            -   `google/gemini-2.0-flash-exp:free`: A free option for coding.
            -   `deepseek/deepseek-chat`: SUPER CHEAP, almost as good as 3.5 sonnet
        -   [OpenRouter Model Rankings](https://openrouter.ai/rankings/programming)

## Your First Interaction with Jamila

Now you're ready to start building with Jamila. Let's create your first project folder and build something! Copy and paste the following prompt into the Jamila chat window:

```
Hey Jamila! Could you help me create a new project folder called "hello-world" in my Jamila directory and make a simple webpage that says "Hello World" in big blue text?
```

**What You'll See:** Jamila will help you create the project folder and set up your first webpage.

## Tips for Working with Jamila

-   **Ask Questions:** If you're unsure about something, don't hesitate to ask Jamila!
-   **Use Screenshots:** Jamila can understand images, so feel free to use screenshots to show him what you're working on.
-   **Copy and Paste Errors:** If you encounter errors, copy and paste the error messages into Jamila's chat. This will help him understand the issue and provide a solution.
-   **Speak Plainly:** Jamila is designed to understand plain, non-technical language. Feel free to describe your ideas in your own words, and Jamila will translate them into code.
